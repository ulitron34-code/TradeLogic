# Reparto recomendado entre Codex y Claude Code

## Codex
- Scaffolding del monorepo y configuración.
- Prisma, migraciones, repositorios y seeds.
- Endpoints, middleware RBAC e idempotencia.
- Docker, CI, pruebas y observabilidad.
- Motor determinista de divisas y costos.

## Claude Code
- Contratos de agentes y prompts versionados.
- Pipeline RAG, recuperación y validación de citas.
- Extracción estructurada de documentos regulatorios.
- Explicaciones de impacto y clasificación.
- Evaluaciones con golden sets y pruebas adversariales.

## Regla de convivencia
Cada tarea tiene dueño, rama y contrato. Ningún agente modifica migraciones, contratos compartidos o políticas de seguridad sin ADR y revisión cruzada.
